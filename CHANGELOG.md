# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-02-16

### Added

- `portcheck kill <port>` command to terminate processes
- `--force` / `-f` flag to skip kill confirmation
- Cross-platform process termination support

### Changed

- Improved process detection reliability

## [0.1.0] - 2026-02-05

### Security

- Safe process termination with explicit confirmation
- No blind process killing

## [0.1.0] - 2026-02-05

### Added

- Initial public release
